# Thư Viện Y Khoa Online

Trang web tập hợp video bài giảng và bản dịch tiếng Việt các guideline y khoa của kênh Thư Viện Y Khoa Online.

- Dựng web: `node build.mjs` → thư mục `dist/` (không cần cài thư viện, Node 18+)
- Xem thử trên máy: `node build.mjs && python3 -m http.server -d dist 8080` rồi mở http://localhost:8080
- Nội dung: `content/` · Hướng dẫn vận hành: [HUONG-DAN.md](HUONG-DAN.md)
